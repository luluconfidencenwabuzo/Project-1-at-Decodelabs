# Project-1-at-Decodelabs
Data cleaning and preparation

## Tool Used
Microsoft Excel

## Project Task
The task for week 1 was to clean and prepare a sales dataset for analysis.

## Task Process
I first went through the instructions for this task, went through the dataset which had 1201 rows and 13 columns

I checked for duplicates using conditional formating

I replaced empty cells found within the "coupon code" column with "NIL" using the replace function

Then, finally formatted it as a table which aids in sorting, filtering and updates your dashboard when new data is added.
